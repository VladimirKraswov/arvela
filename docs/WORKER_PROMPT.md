# Implementation assignment for OpenCode / Qwen

Пользователь попросил, чтобы именно OpenCode с локальной Qwen3.8 Flash Next самостоятельно написал себе desktop-оболочку. Репозиторий уже содержит официальный стартовый Tauri 2 + React/TypeScript проект и спецификацию. Начинай реальную разработку приложения **OpenCode Desktop**.

1. Прочитай AGENTS.md, .pi/TASK.md, README.md и ROADMAP.md; затем нужные разделы docs. Проверь Git, инструменты и живой OpenCode API. Не считывай весь большой OpenAPI файл сразу.
2. Ориентир — рабочая среда наподобие Codex: проекты/сессии слева, настоящий потоковый чат с reasoning/tools, выбор модели/усилия, справа файлы и diff, снизу терминал. Детали и критерии заданы в документации. Не делай iframe поверх существующего сайта вместо самостоятельной оболочки.
3. OpenCode установлен отдельно и должен независимо обновляться. Используй его API, а не копию исходников, не второй движок и не собственную базу разговоров. Не меняй глобальные настройки, чужие проекты, существующие сессии или FreeToken. Сначала используй уже работающий loopback-сервер.
4. Создай короткий план и выполняй M1 → M6 последовательно: код, полезные проверки, работающий вертикальный срез, checkpoint. При нехватке контекста сохрани точный .pi/TASK.md и продолжай через штатную compaction OpenCode. Не останавливайся после одного плана/каркаса. Сам принимай обычные инженерные решения.
5. На каждой стадии отличай реализованные возможности от будущих; обновляй документацию. Никаких фиктивных success-state, декоративных неработающих кнопок и утверждения о полном равенстве с Codex без проверки.
6. Сделай тесты, проверь нативное окно и release .app. В конце установи локальное приложение в пользовательскую Applications и добавь ярлык на Desktop, сохранив старый Qwen OpenCode.app. В отчёте укажи точные пути, проверки, работающие функции и ограничения.

Делай работу инструментами, а не только рассуждай. Режим модели Medium. Разработку выполняй в этом проекте; публикация в GitHub и изменения других приложений не запрошены. Если одна стадия требует нескольких ответов, оставь конкретный checkpoint и не заявляй DONE преждевременно.
