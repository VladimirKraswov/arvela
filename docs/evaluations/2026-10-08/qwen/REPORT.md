# Qwen3.8 Flash Next: OpenCode и Pi, 8 октября 2026

Проверка закончена: протокол **2/2**, задачи по коду **16/24**, браузер
**4/4**. Соединение и инструменты работают с локальной моделью; качество
исправлений пока не позволяет считать все сценарии надёжными. Все ошибки
сохранены, включая отдельную незавершённую попытку.

## Условия

Qwen3.8 Flash Next NVFP4 на одной RTX 5090, FreeToken 0.1.3. Проверенный
checkout движка — `9fbe3b7fb517178c9ac7d2092d4628c78b622a6e`, main,
без изменений. Движок не перезапускался: идентификатор процесса API совпал
до и после серии, финальная проверка здоровья успешна, активных запросов 0.
OpenCode 1.18.18, Pi 0.85.1, macOS ARM64, Node 26.7.0.

В ответах провайдера всех попыток зафиксирован `qwen38-flash-next`.
Рассуждения **Medium**, включён thinking, temperature 1, top-p 0.95,
top-k 20. Оба агента используют одинаковую политику запросов. Облачного
резервного провайдера нет. Модель объявляет окно 262144 токена; эти короткие
задачи **не проверяют заполненное окно 262K**.

Запуски последовательные, по два повтора, порядок агентов и режимов
обращён во втором повторе. Три проекта по пять файлов, suite 2.1.0;
проверки результата находятся вне видимых агенту файлов. Project map
сравнивается в режимах off/tools; память off. Агенты работают в отдельных
временных HOME/XDG с общими ограниченными инструментами. Пользовательские
навыки, истории, настройки, проекты и собственный браузер не используются.
Среда намеренно ограничена: результат не равен качеству полного рабочего
агента со всеми его инструментами.

- Шесть outbox-попыток достигли лимита 300 секунд. Их итоговый код меняет

  Старый счётчик не сохранял тип отказа; точную причину установить нельзя.
- Pi / router / off / повтор 2 перенёс `generation` внутрь `scope` и удалил
  поле верхнего уровня. Это нарушило исходный контракт API.

Исходные утверждения не изменялись. Успешные варианты тоже сохранены.

## Полнота и воспроизводимость

Первый проектный запуск остановлен общим лимитом 3600 секунд после 18 полных
попыток и одной прерванной на 141.7 с. Незавершённая попытка outbox /
OpenCode / tools / повтор 2 сохранена отдельно. В новом отчёте с
`--trial-offset 18` выполнены шесть оставшихся полных попыток; повтор этой
прерванной попытки тоже не прошёл. Завершённые ошибки не перезапускались.
Итого 24 полных проектных результата плюс один отменённый, а не 25
независимых полных тестов.

Архивы: [протокол](protocol/report.json),
[первый запуск](projects-initial/report.json),
[продолжение](projects-continuation/report.json),
[браузер](browser/report.json). Каждый содержит точные версии исходников
стенда и все полученные результаты. Проверено 48 SHA256 исходников, 125
файлов проектов, 27 файлов решений. Все 27 вариантов кода, включая отменённый,
повторно проверены без модели против исходных архивных утверждений.

Стенд получил локальный адаптер, ограниченное ручное продолжение и безопасные
счётчики отказов. Между первым запуском и продолжением изменились наблюдение
за кешем/ошибками и управление планом; запросы модели, инструменты, задачи
и критерии результата остались прежними. Старые отчёты не переписаны.
В протоколе и первом запуске gateway считал только DeepSeek-поле cache hits:
его ноль нельзя трактовать как отсутствие кеша Qwen. Поздний счётчик читает
стандартное OpenAI-поле и отдельно указывает покрытие. На прерванных запросах
usage частичен: неизвестные токены не заменены нулём. Общие известные бюджеты
включают также служебные запросы агентов и отменённую попытку; это не TPS.

В прошлой DeepSeek-серии было 7/24 успешных проектных результатов против
16/24 здесь. Это наблюдение о данных конкретного стенда, а не общий рейтинг:
DeepSeek нормализовал Medium в High, параметры генерации и состояние кеша
отличались. Браузер у DeepSeek также прошёл 4/4, но значительно быстрее;
локальный цикл из 20–21 обращения к модели здесь занимает около трёх минут.

## Практическое решение

Оставить Qwen Medium для повседневного кода и оба агента. После исправлений
обязательно проверять неизменность входных данных, повторную доставку и
совместимость структуры API: именно эти контракты модель здесь нарушала.
Карту проекта включать по потребности, без автоматического добавления в prompt.
Работа браузера с восстановлением после изменения страницы подтверждена;
ускорение его цикла требует отдельного измеряемого изменения, а не объявления
модели безошибочной.

Продакшен-движок, его параметры, приложение 0.2.34 и пользовательские сессии
не менялись. Проверены 21 тест стенда, 644 теста приложения (6 ранее
предусмотренных live-пропусков), TypeScript и production Vite build.
Остались прежние предупреждения сборки о размере bundle и dynamic imports.
Windows/Linux, параллельные сессии, полный контекст и скорость токенов/с
в эту квалификацию не входят.
