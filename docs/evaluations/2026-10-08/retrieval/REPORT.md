# M41: общий поиск и подготовка контекста — 2026-10-08

Три неизменённых задачи M39 (`zero-value`, `idempotent-usage`, `stale-edit`), OpenCode 1.18.18 и Pi 0.85.1, DeepSeek Flash, запрошенный Medium / фактический High по политике провайдера. Два повтора. Первый: OpenCode→Pi и off→tools→context; второй — обратный порядок агентов и режимов. `off` — новый контроль на том же runner; исторические числа M39 не используются как прямое сравнение задержек.

36 независимых проверок кода прошли. 35/36 прогонов полностью успешны; контроль OpenCode `zero-value`, повтор 1, имеет ошибку запроса на пути к провайдеру и частичный usage, хотя код прошёл проверку. Он сохранён как agent-error, а не удалён/перезапущен. 193/194 ответов с usage; известный суммарный расход 423490 токенов, один ответ без usage. Отдельный ранний незавершённый пробный запуск исключён из таблицы: найдено пересечение имён артефактов между режимами, runner исправлен до полного финального сравнения. Его расходы не включены в таблицу.

**Решение: автоматическую подготовку контекста не включать.** В этом маленьком наборе контекст не дал устойчивого ускорения или доказанного улучшения качества. `tools` означает доступность поиска, а не принудительное использование: OpenCode вызвал его 3 раза, Pi — 11. У обоих агентов запросы к памяти добавляли время. Поиск остаётся явным опциональным MCP-инструментом; полезность на больших реальных проектах ещё не измерена.

В тестах `tools/context` использовался настоящий Python-модуль retrieval Hub в отдельной SQLite-базе с искусственными фактами, без решений/oracle. Транспорт eval — ограниченный backend M39; это не замер производительности установленного native MCP и не проверка всего packaged UI. Отдельно подписанный Mac MCP через реальный shared proxy и установленный загрузчик Pi прочитал одобренный факт по HTTPS и отказал после отзыва grant; отдельный OpenCode подтвердил подключение MCP без инференса. Никакие личные сессии, файлы, навыки или локальные GPU в облачные прогоны не передавались.

Полное время включает создание backend/базы, запуск агента, запросы, подготовку контекста и независимую проверку; исключает последующую уборку и предварительную проверку версий CLI. Мало задач/повторов, облачная задержка и кэш влияют на цифры. Вывод не распространяется на качество локального Qwen, большие репозитории или общий интеллект.
