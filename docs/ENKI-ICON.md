# Иконка Enki

Канонический исходник — [`src/assets/enki.svg`](../src/assets/enki.svg):
скруглённая тёмная поверхность и светлая буква E. Это вектор приложения;
переименование файлов само по себе не меняет рисунок.

Для воспроизводимого получения настольных ресурсов:

```sh
npm run tauri -- icon src/assets/enki.svg --output .local/enki-icons
```

Скопируйте соответствующие настольные файлы из `.local/enki-icons` в
`src-tauri/icons`, а `icon.png` — в `src/assets/enki-icon.png`.
Мобильные ресурсы, дополнительно созданные CLI, в этот проект не включаются.
Проверьте маленькую PNG, macOS `.icns`, Windows `.ico`, затем соберите пакет
и проверьте подпись, Info.plist и нативные разрешения.
