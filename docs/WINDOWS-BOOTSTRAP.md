# Первое обновление Enki на Windows через Hub

Старый клиент без обновлений нужно один раз собрать и установить вручную.
Дальше штатный updater использует тот же Hub. Готовый Windows-установщик
на Mac не собирается: ниже инструкции для Windows-агента.

1. Получить `https://192.168.31.223:8443/downloads/latest`.
   Сервер использует частный TLS-сертификат; проверить известный владельцу
   SHA256-отпечаток **сертификата DER**, не SHA1 thumbprint и не хеш PEM-файла:
   `55CC652F9F586DAA0AEA35EF936D8F3C77F86AB53C14E8643D191E35042020FC`.
   Использовать только этот сертификат/изолированное доверие к нему; не отключать
   проверки TLS глобально и не принимать произвольный сертификат.
2. Скачать `source.url` с того же HTTPS origin без перехода на другой origin,
   проверить `source.bytes` и SHA256 (`Get-FileHash -Algorithm SHA256`).
   Распаковать ZIP в новую короткую папку, например `C:\work\Enki-<version>`.
   Не затирать рабочий Git checkout или данные установленного приложения.
   В корне ZIP находятся `package.json` и `src-tauri`.
3. Проверить Node.js 24, npm, актуальный Rust stable с MSVC target, Visual Studio
   C++ Build Tools с Windows SDK и WebView2. Проверить актуальные требования
   установленной версии Tauri перед установкой отсутствующих компонентов.
   Не включать updater signing key: приватный ключ выпуска хранится у владельца
   и для локального NSIS не требуется. Конфигурация установки — currentUser.
4. Из распакованной папки выполнить последовательно, проверяя exit code:

   ```powershell
   npm ci
   npm run build
   npm run build:windows
   ```

   NSIS EXE появится в `src-tauri\target\release\bundle\nsis`.
   Проверить версию установщика против manifest; не подменять её версией main.
5. Найти текущую установку/версию Enki и сделать резервную копию её настроек
   и данных. Сохранить совместимую идентичность `dev.local.opencodedesktop`.
   Штатно завершить Enki **из трея**, дождавшись остановки собственных агентов;
   крестик окна только скрывает приложение. Не завершать чужие OpenCode/Pi,
   серверы и другие приложения. Установить новый NSIS в существующее место
   установки для текущего пользователя, не запускать uninstall с удалением данных.
6. Запустить новую Enki, проверить версию, сохранённые чаты/настройки, OpenCode/Pi,
   отсутствие ошибок загрузки. Настроить **Облачную библиотеку** на
   `https://192.168.31.223:8443` с проверенным публичным сертификатом и отдельным
   Windows device-ключом (либо сохранить уже существующий ключ этой установки).
   Не копировать Mac/admin-ключ. Проверить страницу «Обновления» и связь с Hub;
   новая версия может честно сообщать, что обновлений пока нет.

Прямой ZIP для браузера:
`https://192.168.31.223:8443/downloads/latest/source.zip`.
Для автоматизированной загрузки используйте manifest и его неизменяемую ссылку:
между двумя запросами может появиться более новый stable-релиз.

Эта инструкция не означает, что текущая версия уже собрана/проверена на Windows.
Windows-агент должен сообщить фактические результаты сборки, установки и запуска.
